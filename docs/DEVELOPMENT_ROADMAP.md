# CineRwa Development Roadmap

## Phase 01 (current)
- Brand identity & logo assets.
- Design system & tokens.
- Frontend app: Home, Movies, Series, Movie/Series details, Watch, My List, Search, About.
- Demo data, services, content provider architecture.
- Backend FastAPI foundation (health, config, DB architecture).
- Responsive UI, loading/empty/error states.

## Phase 02
- Backend: MySQL integration, models, migrations.
- TMDB integration (metadata) with attribution.
- JWT authentication & user accounts.
- Real watchlist persistence.

## Phase 03
- Authorized content providers (licensed sources, external links).
- HTML5 player enhancements (subtitles, quality, resume).
- Search improvements, recommendations.

## Phase 04
- Admin dashboard (content, providers, users, analytics).
- Internationalization & expansion beyond Rwanda.
- Performance, SEO, accessibility audit.
