# CineRwa Brand Guidelines

## Name
CineRwa (always written as one word, capital C and R).

## Tagline
"Your World of Cinema."

## Meaning
- CINE: cinema, storytelling, creativity, entertainment, visual experiences.
- RWA: Rwanda, country of origin and cultural inspiration.

## Logo
Assets in `frontend/public/` and `frontend/src/assets/logos/`:
- `logo-primary.svg` — primary horizontal logo (dark background).
- `logo-icon.svg` — standalone icon.
- `logo-compact.svg` — compact navigation logo.
- `favicon.svg` — favicon.
- `logo-dark.svg` — dark-background variant.
- `logo-light.svg` — light-background variant.

## Colors
| Token | Hex |
|---|---|
| Midnight black | #09090D |
| Deep violet | #171525 |
| Primary purple | #8B5CF6 |
| Lavender | #C4B5FD |
| White | #FFFFFF |
| Secondary text | #A1A1AA |

Purple is the primary brand accent.

## Typography
- Family: Inter (with system fallbacks).
- Weights: 400, 500, 600, 700, 800.

## Visual Language
- Premium cinematic atmosphere.
- Large-format movie artwork.
- Subtle purple gradients.
- Elegant typography, strong hierarchy, refined spacing.
- Smooth transitions.

## Avoid
- Excessive gradients, overloaded layouts, generic admin-dashboard aesthetics.
- Excessive rounded cards, random color combinations, copying competitors.
